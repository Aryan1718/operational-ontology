# Frontend

This frontend skeleton provides:

- a Next.js App Router shell;
- responsive placeholder routes for planned application sections;
- a centralized typed API client;
- TanStack Query setup;
- a backend health check with loading, success, and failure states;
- frontend test, lint, typecheck, and build configuration.

This phase does not implement authentication, object exploration, ontology browsing, graph behavior, governed actions, audit history, or assistant workflows.
