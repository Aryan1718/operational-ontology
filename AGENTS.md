# Agent Guidance

Coding agents working in this repository should:

1. Read the root [`agent.md`](agent.md) before making changes.
2. Read the task-specific context document under `docs/` that matches the layer being changed.
3. Preserve the ontology, action, permission, and AI boundaries described in the context files.
4. Avoid turning the project into unrestricted operational CRUD.
5. Reuse the existing repository structure and naming before introducing new patterns.
6. Avoid unrelated changes while implementing the requested task.
